# CUMCM 优秀论文蒸馏规则（WriterAgent 运行时版）

本规则由项目 `skills/cumcm-latex` 新版模板蒸馏而来，直接供
WriterAgent 运行时加载。若旧提示词中的示例、固定字数或通用套话与本规则冲突，
以本规则为准。

## 一、总目标

把论文写成可核验、可复现、能逐问回答赛题的建模报告，而不是算法名词、
通用背景和漂亮句式的集合。每一问必须形成以下闭环：

`任务目标 → 输入证据 → 变量与假设 → 数学模型 → 求解方法 → 结果 → 验证 → 直接结论`

章节编号可以调整，但闭环不得缺失。

## 二、真实性与证据

1. 只使用题目、附件、建模手方案、代码手真实输出、已生成图表和可核验文献。
2. 不得猜测数值、样本量、参数、拟合优度、误差、运行时间、文献或 DOI。
3. 证据缺失时保留 `[待补：具体证据]`，不要用“效果良好”等套话掩盖缺口。
4. 摘要、正文、表格、图像和附件中的数值、单位与问题编号必须一致。
5. 每个关键结论都应能追溯到表图、计算输出、代码/推导、输入数据和假设。
6. 随机算法必须说明随机种子或重复试验，并报告结果波动；没有证据时不得声称
   获得全局最优。
7. 参考文献只保留真实查阅且正文实际使用的来源。

## 三、摘要采用结果优先结构

1. 用一至两句界定研究对象、核心矛盾和总体路线，不写冗长背景。
2. 每一问用独立语义单元说明：
   - 建立什么模型；
   - 怎样估计或求解；
   - 得到什么数值、区间、排序、方案或判断；
   - 采用什么指标或试验验证。
3. 关键结果带单位、场景和合理有效数字。
4. 末句概括稳健性、适用边界或支撑材料。
5. 给出 3–5 个能够检索论文核心内容的关键词。

摘要不得只列算法名，也不得出现正文没有证明的结论。

## 四、章节功能

### 问题重述

忠实压缩研究对象、已知条件、输入、输出和逐问要求。保留题目要求的文件或
方案格式，不照抄大段原题，不提前展开模型推导。

### 问题分析

逐问说明任务类型、可用信息、关键难点、模型选择理由、问题间依赖、预期输出和
验证计划。问题分析承担路线图功能，不与模型建立章节重复。

### 模型假设

每条假设必须说明具体对象、成立范围、采用理由、对模型的简化作用和潜在偏差。
删除后文未使用的假设。不得使用“数据均真实可靠”“不考虑特殊情况”等万能套话。

### 符号与数据

符号说明至少包含含义、单位和类型/取值域。说明数据来源、范围、样本量、缺失值、
异常值、重复记录、单位换算、时间/空间对齐、特征构造和数据划分。量化处理前后的
样本变化，避免目标泄漏和未来信息泄漏。

### 模型建立与求解

每一问依次完成：

1. 写出本问目标和可交付答案。
2. 定义变量、参数、集合、下标、单位和取值范围。
3. 给出机理关系、目标函数、约束、损失函数或状态转移规则。
4. 解释核心公式的含义、来源、量纲和适用条件。
5. 说明算法、初始化、关键参数、停止条件、软件/求解器和失败处理。
6. 用表图呈现真实结果，并解释数量级、趋势、极值、差异和现实意义。
7. 使用与模型类型匹配的验证。
8. 用“本问结论”直接回答题目，并说明结果如何传入下一问。

代码不是数学模型。正文保留核心公式和算法逻辑，完整代码放附录或支撑材料。

### 验证、敏感性与不确定性

验证检查模型是否正确实现假设、规律和约束；敏感性分析研究输入或参数扰动；
不确定性分析量化测量、抽样、估计、离散或随机误差。三者不得混为一谈。

选择真正影响竞赛结论的参数，给出基准值、扰动范围、比较指标、稳定区间和
失稳阈值。只画曲线而不给定量判断不算完成分析。

### 模型评价

优点必须由精度、计算量、解释性、约束适应性或对比结果支撑。缺点必须写明失效
条件和偏差方向。改进应逐一对应缺点，并说明新增数据、方法或计算成本。推广要写
明需要重估的参数和最低数据条件。

## 五、按模型类型追加要求

### 机理与微分方程

- 说明守恒律、经验定律或几何关系的来源。
- 给出初始条件、边界条件和参数来源。
- 检查量纲、离散步长、稳定性和收敛性。
- 用已知特例、守恒误差或观测数据验证。

### 优化与调度

- 明确连续、整数、0-1 和时序决策变量。
- 将每条现实规则映射为约束。
- 报告可行性、目标值以及可得的最优界或间隙。
- 与简单基线或现行方案比较。
- 启发式算法报告多次运行的最好值、均值和标准差。

### 回归、分类与预测

- 说明目标、特征构造和特征在预测时是否可用。
- 使用符合任务的训练/验证/测试划分；时间序列禁止泄漏未来信息。
- 给出简单基线和多个互补指标。
- 检查残差、校准、过拟合、类别不平衡和分布漂移。
- 使用置信区间、预测区间或重采样量化不确定性。

### 综合评价与排序

- 说明指标方向、量纲、标准化和权重来源。
- 检查一致性、共线性和重复计权。
- 通过权重扰动、删减指标或更换标准化方法检查排序稳定性。
- 报告并列、临界和排名反转。

### 仿真与策略评估

- 定义实体、状态、事件、转移规则、时间步和终止条件。
- 说明随机分布、参数估计和预热期。
- 运行足够重复次数并报告均值、方差或置信区间。
- 与理论特例、历史记录或基线策略比较。

## 六、图、表、公式

1. 图、表、公式按出现顺序编号并在正文中交叉引用。
2. 图题说明对象、场景和变量；坐标轴、图例、单位与字号在 PDF 中可读。
3. 表题置于表上，列名包含单位，小数位符合数据精度。
4. 核心公式在公式前说明目的，在公式后解释符号和现实含义。
5. 检查量纲、上下标、求和范围、边界和不等号方向。
6. 图表必须服务于结论；不得只写“由图可知效果很好”。
7. 不用截图代替可排版公式和表格。

## 七、篇幅原则

质量和证据优先，不为凑固定字数重复背景、题意、算法教科书知识或中间日志。
复杂问题可以充分展开，简单问题应保持简洁。任何建议字数都只是上限管理参考，
不能凌驾于逐问闭环、真实性和可复现性。

## 八、交付前检查

- 每一问都有模型、真实结果、验证和直接答案。
- 摘要逐问报告关键结果，且与正文一致。
- 所有变量、缩写、图、表、公式和文献均已定义或引用。
- 没有 `[待补`、`TODO`、虚构引用、无来源数值或无单位关键结果。
- 没有“效果显著”“精度较高”等无指标判断。
- 图表路径、附件名和问题编号有效且一致。
- 最终 PDF 中首页、目录、跨页表格、公式、图片、页码和附录可正常阅读。
