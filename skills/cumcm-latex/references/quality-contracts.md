# CUMCM 论文质量契约

用本契约约束内容真实性、逐问闭环和可复现性。目录可以变化，契约不能缺失。

## 1. 全局证据契约

提交前为每个关键结论保留追溯链：

`结论 → 表/图/数值 → 计算输出 → 代码或推导 → 输入数据与假设`

满足以下规则：

- 任何具体数值都来自题设、数据、真实计算或可核验文献。
- 摘要中的数值与正文、表格、附件完全一致。
- 四舍五入后仍应满足关键约束；必要时说明内部计算精度。
- 外部资料记录作者/机构、标题、年份、链接或 DOI 和访问日期。
- 图表能够由保存的代码和数据重新生成。
- 随机算法记录随机种子、重复次数及结果波动。
- 缺失证据明确标为 `[待补：...]`，交付前要么补齐，要么删除相应结论。

## 2. 章节契约

### 标题

必须包含：

- 研究对象或场景。
- 核心建模目标，必要时包含主要模型类别。

禁止：

- 只复制赛题名称。
- 用过长的算法清单替代研究主题。
- 使用“研究”“分析”等无法区分论文内容的空泛标题。

### 摘要

必须包含：

- 总体建模主线。
- 每一问的模型、求解方式、关键结果和验证。
- 至少一组能直接回答赛题的定量或明确结论。
- 3–5 个有效关键词。

禁止：

- 引用公式编号、图表编号或未在正文证明的结果。
- 只写“建立模型并用软件求解”。
- 只有过程没有结果，或只有结果没有模型依据。
- 将“准确率较高”“拟合效果良好”作为无指标结论。

### 问题重述

必须包含：

- 研究对象、已知条件、输入、输出和逐问要求。
- 题目要求提交的文件、方案或评价指标。

禁止：

- 大段复制原题。
- 改变题意、遗漏限制条件。
- 提前塞入长篇模型推导。

### 问题分析

必须包含：

- 每问的任务类型、关键难点和可用信息。
- 模型选择理由和预期输出。
- 问题间的依赖关系。
- 验证计划。

禁止：

- 与“模型建立”章节逐句重复。
- 只有算法名称，没有选择依据。
- 把技术路线图当装饰而不解释数据流。

### 模型假设

必须包含：

- 假设的具体对象、成立范围和采用理由。
- 假设如何简化后续模型。
- 对关键近似造成的偏差或局限的说明。

禁止：

- “数据均真实可靠”“不考虑所有意外”等无证据套话。
- 列出后文从未使用的假设。
- 将题设事实、定义或已观测结果写成假设。

### 符号说明

必须包含：

- 含义、单位和必要的取值域/类型。
- 下标、集合和向量的定义。
- 全文一致的记法。

禁止：

- 一个符号在不同章节代表不同对象却不声明。
- 变量首次出现时既不入表也不就地解释。
- 用缩写或代码列名替代数学含义。

### 数据处理

必须包含：

- 数据来源、范围、样本量和关键字段。
- 缺失、异常、重复、单位、时间/空间对齐的审计。
- 每项处理方法、阈值、理由和处理前后样本变化。
- 训练/验证/测试或时间切分策略。

禁止：

- 在全量数据上标准化或调参后再声称是独立测试。
- 删除异常值但不给规则和数量。
- 只展示大量统计图而不说明它们如何影响建模。
- 使用未来信息、目标泄漏或跨时间错误匹配。

### 模型建立

必须包含：

- 本问目标、变量、参数、集合与单位。
- 核心数学关系及其现实含义。
- 目标函数、约束、损失函数或状态转移规则。
- 初始/边界条件和适用范围。
- 与上一问或下一问的数据接口。

禁止：

- 仅用自然语言说“使用某算法”而没有数学定义。
- 给出公式却不解释符号或来源。
- 用代码截图代替模型。
- 为增加复杂度而并列多个没有贡献的模型。

### 求解方法

必须包含：

- 可复现的输入、初始化、迭代步骤、参数和停止条件。
- 软件、求解器及关键版本。
- 算法选择理由和失败/不可行处理。

禁止：

- 隐藏影响结论的人工调参。
- 随机算法只运行一次且不记录种子。
- 声称获得全局最优却没有理论保证、界或多起点证据。

### 结果与结论

必须包含：

- 带单位、场景和合理有效数字的直接答案。
- 关键结果表或图。
- 与基线、题设阈值或不同方案的比较。
- 对极值、趋势、差异和现实意义的解释。
- 每问末尾的明确结论。

禁止：

- 只写“结果见表/图”。
- 报告比输入精度更高的无意义小数位。
- 用百分比改善但不报告基准值。
- 展示大量中间输出而不回答题目。

### 验证、敏感性与不确定性

必须包含：

- 与模型类型匹配的验证。
- 指标、判据、对照和真实结果。
- 关键参数的扰动范围与结论稳定区间。
- 主要误差或不确定性来源。

禁止：

- 将训练拟合度当作全部验证。
- 只画曲线而不给定量判断。
- 把“参数变化导致输出变化”直接称为稳健。
- 选择对结论无关的参数做形式化敏感性分析。

### 模型评价

必须包含：

- 由正文证据支撑的优点。
- 明确的失效条件、偏差方向或数据限制。
- 与局限逐一对应的改进。
- 推广时需要重估的参数和最低数据条件。

禁止：

- “适用范围广、精度高、操作简单”等空泛套话。
- 只写优点不写边界。
- 提出与缺点无关的“使用更先进算法”。

### 参考文献与附录

必须包含：

- 正文中真实使用且可以定位的来源。
- 统一格式及网页访问日期。
- 完整代码或支撑材料的运行说明和文件索引。

禁止：

- 编造作者、期刊、DOI 或网页。
- 列出正文从未引用的“装饰性”文献。
- 把关键模型、核心结果全部移入附录。

## 3. 按模型类型追加检查

### 机理与微分方程

- 说明守恒律、经验定律或几何关系的来源。
- 检查每项量纲。
- 给出初始条件、边界条件和参数来源。
- 说明解析/数值方法、网格或步长、稳定性和收敛性。
- 用已知特例、守恒误差或实验数据验证。

### 优化与调度

- 列出决策变量类型，尤其是整数、0-1 和时序变量。
- 逐条映射现实规则到约束。
- 报告可行性、目标值、最优界或最优性间隙。
- 提供简单基线、现行方案或无优化方案用于对比。
- 对权重、成本、容量等关键参数做敏感性或情景分析。
- 若用启发式算法，报告多次运行分布和最好/均值/标准差。

### 回归、分类与预测

- 说明目标变量、特征构造和时间可用性。
- 使用符合任务的划分方式，时间序列不得随机泄漏未来信息。
- 给出简单基线，并报告多个互补指标。
- 检查残差、校准、类别不平衡、过拟合和分布漂移。
- 用置信区间、预测区间或重采样量化不确定性。

### 综合评价与排序

- 解释指标方向、量纲和标准化方式。
- 权重来源可复核；主客观组合时说明组合规则。
- 检查一致性、共线性或重复计权。
- 通过权重扰动、删减指标或不同标准化方式检查排序稳定性。
- 报告并列、临界和排名反转情形。

### 仿真与策略评估

- 定义实体、状态、事件、转移规则、时间步和终止条件。
- 说明随机分布、参数估计和预热期。
- 运行足够重复次数并给出均值、方差或置信区间。
- 与理论特例、历史记录或基线策略比对。
- 分离偶然波动与策略真实差异。

### 图论、网络与空间模型

- 定义节点、边、方向、权重、距离和连通规则。
- 说明坐标系、投影、空间尺度和距离计算。
- 验证网络构建是否遗漏或错误连接。
- 区分拓扑距离、几何距离和实际成本。
- 对阈值、邻域半径或边权扰动检查结论稳定性。

## 4. 图、表、公式契约

### 图

- 正文先引出再展示，并在图后解释结论。
- 图题说明对象、场景和变量。
- 坐标轴、单位、图例、颜色和字号在最终 PDF 中清晰。
- 同类图保持颜色、刻度和数值范围一致。
- 不使用带有无关工具栏、窗口边框或调试输出的截图。
- 颜色之外再用线型、标记或文字保证黑白可读性。

### 表

- 表题放在表上方；列名包含单位。
- 小数位和有效数字按测量精度统一。
- 超长表移到附录，正文保留关键行或汇总。
- 使用加粗或注释突出最优值时，说明最优判据。
- 每张表都在正文被引用并解释。

### 公式

- 核心公式编号，后文通过编号引用。
- 公式前说明目的，公式后解释符号和现实含义。
- 检查量纲、上下标、求和范围、边界和不等号方向。
- 推导中的近似、线性化或松弛必须说明条件。
- 同一对象的标量、向量、矩阵记法保持一致。

## 5. 终稿评分表

按 100 分自评，任一“真实性”项目不合格则不得交付：

| 维度 | 分值 | 满分标准 |
|---|---:|---|
| 真实性与追溯 | 15 | 数值、图表、文献均可追溯，无编造 |
| 摘要与直接答案 | 12 | 逐问含方法、结果、验证，结论具体 |
| 问题分析与结构 | 10 | 主线清晰，问题依赖和技术路线明确 |
| 数学模型完整性 | 18 | 变量、公式、约束、假设、单位完整 |
| 求解可复现性 | 10 | 算法、参数、环境和停止条件完整 |
| 结果解释 | 12 | 图表服务结论，有基线和现实解释 |
| 验证与稳健性 | 13 | 验证匹配模型，扰动和不确定性充分 |
| 评价与推广 | 5 | 优缺点有证据，改进与边界具体 |
| 排版与引用 | 5 | 编号、交叉引用、文献、PDF 版式规范 |

建议总分达到 85 分以上，且“真实性与追溯”“数学模型完整性”“验证与稳健性”分别不低于该项分值的 80%。

## 6. 最终机械检查

搜索全文并逐项处理：

- `[待补`
- `TODO`、`TBD`、`xxx`
- “结果很好”“效果显著”“精度较高”“具有现实意义”
- 未定义的拉丁字母和缩写
- 没有单位的关键数值
- 没有正文引用的图、表、公式和文献
- 摘要与正文不一致的数值
- 相同图表标题、重复章节或复制遗留的问题编号
- 失效的图片路径、附件名和交叉引用
- 超出数据精度的长小数

最后逐页查看 PDF，而不是只依赖源文件或编译成功状态。
